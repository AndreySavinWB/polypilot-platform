# Архитектура агентов PolyPilot

> **Master pipeline:** [[PROBABILITY_INTELLIGENCE_ENGINE]] · MVP → [[INTELLIGENCE_ENGINE_MVP]] · Data flow → [[INTELLIGENCE_DATA_FLOW]]

> Внутренняя система, которая объясняет, как PP действительно мониторит, сравнивает и готовит аналитику.

---

## Полный цикл события

```text
Market Scanner → Priority Agent → Event Normalizer
  ↓
Whale Intelligence Agent   ← Уровень 2 · деньги
  ↓
Evidence Collector       ← Уровень 3 · информация
  ↓
Contradiction · Comparable · Probability Model
  ↓
Risk Officer → Verdict Agent → Publishing Agent
  ↓
Monitoring Agent → Memory → Autopsy
```

---

## Слои системы

| Слой | Что делает |
|------|------------|
| Data Layer | Polymarket, **MI (киты, flow)**, новости, social, trends |
| Agent Layer | специализированные агенты |
| Memory Layer | события, версии анализа, история изменений |
| Scoring Layer | Priority, Edge, Risk, Confidence |
| Product Layer | карточки, War Room, алерты, PRO |

## Принцип доверия

Каждая карточка PP должна иметь доказуемую родословную:

```text
кто нашёл событие → какие данные проверил → какие риски нашёл
→ почему появился verdict → что изменилось после публикации
```

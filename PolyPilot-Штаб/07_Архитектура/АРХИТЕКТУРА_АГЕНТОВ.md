# Архитектура агентов PolyPilot

> Внутренняя система, которая объясняет, как PP действительно мониторит, сравнивает и готовит аналитику.

---

## Полный цикл события

```text
Market Scanner
  ↓
Priority Agent
  ↓
Event Intake
  ↓
Research Agents
  ↓
Analytics Agents
  ↓
Risk Officer
  ↓
Verdict Agent
  ↓
Publishing Agent
  ↓
Monitoring Agent
  ↓
Update / Autopsy
```

---

## Слои системы

| Слой | Что делает |
|------|------------|
| Data Layer | Polymarket, новости, соцсети, price history |
| Agent Layer | специализированные агенты |
| Memory Layer | события, версии анализа, история изменений |
| Scoring Layer | Priority, Edge, Risk, Confidence |
| Product Layer | карточки, War Room, алерты, PRO |

---

## MVP-сеть агентов

| Агент | Статус |
|-------|--------|
| Market Scanner / Priority Agent | P0 ✅ `rubric_v1` зафиксирован |
| News Scout | P0 |
| Risk Officer | P0 |
| Verdict Agent | P0 |
| Probability Analyst | P1 |
| Contrarian Agent | P1 |
| Monitoring Agent | P1 |
| Autopsy Agent | P2 |

---

## Принцип доверия

Каждая карточка PP должна иметь доказуемую родословную:

```text
кто нашёл событие → какие данные проверил → какие риски нашёл
→ почему появился verdict → что изменилось после публикации
```

## Первая реализация

Polymarket event → Priority → News Scout → Risk Officer → Verdict

# Когда переходить на OpenRouter

> **Сейчас:** `LLM_PROVIDER=polza`, ключ `POLZA_API_KEY`.  
> **OpenRouter:** код уже поддерживается, но **не используется** — оплата недоступна по региону (июнь 2026).

---

## Зачем этот файл

Чтобы не гадать «пора ли OpenRouter». Когда наступит один из триггеров ниже — **скажу тебе явно** в чате: «пора подключать OpenRouter».

---

## Сейчас Polza достаточно, если:

- harvest и `test_llm.py` проходят без ошибок;
- verdict / War Room на русском **вызывают доверие** (scorecard ≥ 4/5);
- стоимость harvest в месяц укладывается в бюджет;
- одной модели `gpt-4o-mini` хватает для всех агентов.

---

## Триггеры «пора OpenRouter» (любой из списка)

| # | Сигнал | Почему |
|---|--------|--------|
| 1 | **Качество** — после scorecard 10+ событий Polza/gpt-4o-mini стабильно слабый русский, галлюцинации, плохой JSON | Нужны другие модели (Gemini, Claude, …) через один API |
| 2 | **A/B моделей** — хотим сравнить 2–3 модели на одних событиях без смены провайдера | OpenRouter = каталог моделей одной строкой в `LLM_MODEL` |
| 3 | **Стоимость при масштабе** — cron 4×/день × 10 событий × 4 агента дороже $X/мес на Polza | На OpenRouter часто дешевле flash-модели |
| 4 | **Polza недоступен** — API down, лимиты, модель снята | Fallback-провайдер |
| 5 | **Этап 4+** — News Scout с несколькими LLM-ролями, Autopsy, PP Check онлайн с очередью | Разные модели под задачу (дешёвая для scan, сильная для verdict) |
| 6 | **Спецмодели** — нужен reasoning / long context, чего нет в Polza | Только через агрегатор |

---

## Как переключиться (когда придёт время)

1. Пополнить https://openrouter.ai → ключ  
2. В `.env` / Railway / GitHub Secret:

```env
LLM_PROVIDER=openrouter
OPENROUTER_API_KEY=sk-or-v1-...
LLM_MODEL=openai/gpt-4o-mini
```

3. В `harvest.yml` — secret `OPENROUTER_API_KEY` (инструкция в коммите от 2026-06-09, код не удалён)

Код: `backend/src/services/llm.py` — провайдер `openrouter` уже есть.

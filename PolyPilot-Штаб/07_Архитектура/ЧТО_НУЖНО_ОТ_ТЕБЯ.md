## Нужно только от тебя

### 1. API key OpenRouter (5 минут)

1. [openrouter.ai/keys](https://openrouter.ai/keys) → создать ключ (`sk-or-v1-...`)
2. Открыть `backend/.env` **в Cursor**
3. Вставить ключ в `OPENROUTER_API_KEY=sk-or-v1-...`
4. Убедиться: `LLM_PROVIDER=openrouter`, `LLM_MODEL=openai/gpt-4o-mini`
5. Сохранить: **Ctrl+S**
6. **Не отправлять ключ в чат**

> Polza (`POLZA_API_KEY`) — legacy, всё ещё работает при `LLM_PROVIDER=polza`.

### 2. Перезапуск backend (1 минута)

```powershell
cd d:\Andrey\PolyPilot\PolyPilot-Backend
.\run.ps1
```

### 3. Перепрогон с LLM (1 команда)

```powershell
.\scripts\run_harvest.ps1
```

### 4. Оценка 3–5 событий глазами (15–20 минут)

Открой `PolyPilot-Backend/data/test_events.json` или [[ТЕСТОВЫЕ_СОБЫТИЯ]].

Для событий #1, #4, #6 ответь себе:
- понятен ли verdict?
- есть ли доверие?
- не выглядит ли как скам?
- можно ли это показать в War Room?

Запиши в scorecard в [[ТЕСТОВЫЕ_СОБЫТИЯ]].

> **Версия Priority Agent:** `rubric_v1`

## Что зафиксировано

### 1. Визуальный MVP (сайт)

- HTML-прототип `platform/` — **готов**, этап MVP закрыт
- Страница событий: **ОНЛАЙН (Полимаркет)** + **ДЕМО** разделены
- Русский язык в интерфейсе и live-карточках

### 2. Backend-лаборатория

- `backend/` — Python API на порту 8787
- Polymarket Gamma API (без ключа)
- LLM через Polza.ai (`LLM_PROVIDER=polza`)
- Portable Python в `.runtime/`

### 3. Priority Agent — рубрика v1 (★ зафиксировано)

Полное описание: [[ПРИОРИТЕТ_АГЕНТ]]

| Параметр | Значение |
|----------|----------|
| Скан пула | до **300** активных событий |
| Hard Gates | 8 жёстких отсечек мусора |
| Веса рубрики | объём 25%, ликвидность 20%, новости 25%, резолв 15%, горизонт 10%, цена 5% |
| Порог `accepted` | score ≥ **70** |
| Порог `watchlist` | score ≥ **55** |
| Иначе | `rejected` |
| Полный анализ | топ **10** (`PP_TOP_N`) |
| LLM-уточнение | топ-20 кандидатов (новости + резолв) |

Код: `backend/src/agents/priority.py`

### 4. Цепочка агентов P0

```text
Скан Polymarket (300)
  → Priority Agent (рубрика v1)
  → News Scout
  → Risk Officer
  → Verdict Agent
  → sync на сайт (events-live.js)
```

### 5. Команды запуска

```powershell
# Backend API
cd backend
.\run.ps1

# Полный цикл: скан → топ-10 → анализ → сайт
.\.runtime\python.exe scripts\harvest_test_events.py

# Только синк на сайт (без LLM-анализа)
.\.runtime\python.exe scripts\sync_live_to_mvp.py
```

### 6. Файлы данных

| Файл | Назначение |
|------|------------|
| `data/priority_scan.json` | отчёт последнего скана (сколько отсеяно / принято) |
| `data/test_events.json` | топ-N с полным анализом агентов |
| `data/test_events_summary.json` | краткая сводка |
| `platform/data/events-live.js` | live-карточки на сайте |

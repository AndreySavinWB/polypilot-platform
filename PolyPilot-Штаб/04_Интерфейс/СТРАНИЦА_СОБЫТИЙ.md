# Страница событий (лента)

## Файл MVP

`PolyPilot-MVP/app/events.html`

## Задачи экрана

- Сетка / лента **CLOSED CARD**
- Фильтры UI: категория, риск, Edge (фильтрация по `events.json` на JS)
- Виджет **Mispricing Radar** (Phase 5)
- Клик → `event.html?id=`

## Состояния tier

| Tier | Поведение |
|------|-----------|
| Guest | редирект или ограничение (см. воронку) |
| Pulse | 5 событий / день (можно пометить «лимит») |
| Trial / PRO | полная лента |

# Визуальный стиль PolyPilot

## Направление

- **dark premium**, futuristic  
- Bloomberg Terminal / Palantir / Perplexity  
- AI-native, не «крипто-скам»

## Цвета (ориентир)

| Роль | Значение |
|------|----------|
| Фон | тёмный (#0a0e17 и близкие) |
| Accent | синий → фиолетовый градиент |
| Текст | белый / серый |
| Glow | мягкий, на карточках и CTA |

## Типографика

- Современный sans-serif (Inter, DM Sans или аналог)
- Крупные заголовки на hero
- Читаемые цифры для Edge / вероятностей

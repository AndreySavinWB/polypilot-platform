# AI-агенты PolyPilot (War Room)

> В MVP — **только UI и тексты-моки**, без LLM.  
> Цель: ощущение «штаба», не один чат.

| Агент | Роль | Что показывает в UI |
|-------|------|---------------------|
| **News Scout** | Новости | Что изменилось за 15 мин |
| **Odds Watcher** | Рынок | Вероятность vs объём |
| **Risk Officer** | Риски | Ликвидность, резолв, флаги |
| **Thesis Builder** | Тезис | 3 «за» и 3 «против» |
| **Devil's Advocate** | Контртезис | Почему рынок может быть прав |

После прогона агентов → **PP Verdict** + **confidence %**.

## Анимация (HTML MVP)

- Последовательная подсветка агентов 5–8 сек
- Кнопка «Пропустить»
- Guest: только 2 агента видны, остальное за paywall

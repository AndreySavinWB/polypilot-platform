# Как пользоваться штабом PolyPilot

## Obsidian

1. Открыть vault: папка **`PolyPilot-Штаб`**
2. Стартовая заметка: **[[ДОМ_ШТАБ]]** (закрепи в избранном / pin)
3. Указатель master-файлов: **[[DOC_INDEX]]**
4. Связи `[[имя файла]]` — кликабельная навигация между документами
5. Canvas: **[[PolyPilot-Ecosystem.canvas]]** — визуальная карта (в `01_Стратегия`)

## Cursor (AI)

При работе над кодом указывай фазу из [[ДОРОЖНАЯ_КАРТА]]:
- «Делаем Phase 2» — не смешивать с Phase 5
- Прикладывай [[AI_КАРТОЧКА_СОБЫТИЯ]] и скрины из `04_Интерфейс/Референсы/`

## Куда писать новое

| Ты решил… | Куда |
|-----------|------|
| Изменить видение / тарифы | [[КОНТЕКСТ_ПРОЕКТА_2.0]] или [[MONETIZATION_STATE]] |
| Описать экран или блок UI | `04_Интерфейс/` |
| Описать фичу продукта | `02_Продукт/` |
| Идея «может быть потом» | [[БЭКЛОГ_ИДЕЙ]] (`08_Идеи/`) |
| Устарело | перенести в `99_Архив/` |

## Именование файлов

- Русский язык, **ВЕРХНИЙ_РЕГИСТР_С_ПОДЧЁРКИВАНИЕМ.md**
- Папки: **`NN_Название`** (номер = порядок в сайдбаре)
- Не дублировать одну тему в 3 файлах — одна «правда», остальное ссылки. См. [[DOC_INDEX]].

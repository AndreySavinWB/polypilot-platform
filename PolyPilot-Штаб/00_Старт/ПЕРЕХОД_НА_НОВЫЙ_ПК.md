# Переход PolyPilot на новый Windows-ПК

> **Дата:** 14 июня 2026  
> **Зачем:** старый ПК «накрывается» — переносим код, секреты, штаб и рабочую среду без потери контекста.

---

## Главная идея (простыми словами)

| Что | Где живёт | Нужно ли копировать вручную? |
|-----|-----------|--------------------------------|
| **Код сайта + backend + доки** | GitHub | ❌ — `git clone` на новом ПК |
| **Prod (сайт онлайн)** | Vercel | ❌ — уже в облаке, деплой с GitHub |
| **Prod backend** | Railway | ❌ — переменные в панели Railway |
| **Секреты локально** | `backend/.env` | ✅ **обязательно** — не в git |
| **Portable Python** | `backend/.runtime/` | ✅ — не в git (~100 MB) |
| **Obsidian vault** | `PolyPilot-Штаб/` | ✅ в git (коммить перед переездом) |
| **Cursor (настройки, skills)** | `%USERPROFILE%\.cursor\` | ✅ по желанию |
| **История чатов Cursor** | `%USERPROFILE%\.cursor\projects\...` | ✅ по желанию (архив) |

**Вывод:** GitHub + бэкап `.env` + копия `.runtime` = 95% переезда. Остальное — облако или опционально.

## Дорожная карта переезда

### Фаза A — на старом ПК (сегодня, ~30–60 мин)

```text
A1  Закоммитить и запушить всё важное в GitHub
A2  Запустить backup-before-move.ps1 → папка на флешку / облако
A3  Проверить: .env, .runtime, Cursor-бэкап на месте
A4  Записать пароли (GitHub, Vercel, Railway, Polza, Telegram) в менеджер
```

### Фаза B — на новом ПК (день 1, ~45 мин)

```text
B1  Git, Cursor, Obsidian, Python (или копия .runtime)
B2  git clone → d:\Andrey\PolyPilot
B3  Восстановить backend\.env из бэкапа
B4  setup-new-pc.ps1 или ручная проверка
B5  Открыть vault Obsidian: PolyPilot-Штаб
B6  Открыть проект в Cursor → POLYPILOT_STATE.md + ДОМ_ШТАБ.md
```

### Фаза C — проверка «всё работает» (~15 мин)

```text
C1  Сайт локально: platform/app/events.html в браузере
C2  Backend: cd backend → .\run.ps1 → http://127.0.0.1:8787/health
C3  Harvest (опционально): .\.runtime\python.exe scripts\harvest_test_events.py
C4  Prod: https://polypilot-platform.vercel.app/app/events.html
C5  Новый чат Cursor: «прочитай POLYPILOT_STATE.md и продолжай этап 4c»
```

## Шаг A2 — Бэкап секретов и локального (скрипт)

Из корня репо:

```powershell
cd d:\Andrey\PolyPilot
powershell -ExecutionPolicy Bypass -File scripts\migration\backup-before-move.ps1
```

Скрипт создаст папку вида:

```text
D:\PolyPilot-Migration-Backup\2026-06-14_HH-mm\
├── backend.env                 ← копия backend\.env
├── backend.runtime/            ← portable Python (если есть)
├── cursor-user-settings.json   ← опционально
├── cursor-skills/              ← опционально
├── agent-transcripts/          ← история чатов Cursor
├── MIGRATION_MANIFEST.txt      ← что скопировано
└── git-status.txt              ← снимок git status
```

**Куда положить:** внешний диск, OneDrive, Google Drive, зашифрованный архив (7-Zip + пароль).


## Секреты — чеклист (не терять)

Заполни у себя (не в git):

| Секрет | Где сейчас | Как восстановить на новом ПК |
|--------|------------|------------------------------|
| `POLZA_API_KEY` | `backend/.env` | из бэкапа `.env` |
| `TELEGRAM_BOT_TOKEN` | `backend/.env` + Railway | бэкап / Railway dashboard |
| `TELEGRAM_CEO_CHAT_ID` | `backend/.env` | бэкап |

## Если что-то пошло не так

| Проблема | Решение |
|----------|---------|
| `Portable Python not found` | Скопировать `backend/.runtime` с бэкапа или установить Python 3.12 |
| Backend 500 / нет LLM | Проверить `POLZA_API_KEY` в `.env` |
| Старый UI на Vercel | Ctrl+Shift+R; подождать деплой 1–2 мин после push |
| Потерян `.env` | Railway dashboard + Polza.ai новый ключ + `.env.example` |
| Obsidian пустые ссылки | Открыть vault `PolyPilot-Штаб`, не корень репо |

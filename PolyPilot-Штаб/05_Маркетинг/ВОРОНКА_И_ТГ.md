# Воронка и Telegram

> Полная версия: [[МОНЕТИЗАЦИЯ]]

## Схема

```text
Креатив → guest-event → вау 60–90 сек
→ «Войти через Telegram» → Pulse + PRO Trial 7 дней
→ триггеры → PRO 2 990 ₽ / 24 990 ₽ год
```

## Правила

- **ТГ бесплатный** — не касса
- **Обучение** — в `learn.html`, не блокер
- **Деньги** — только в PP

1 пост/день + кнопка в **конкретное событие**.

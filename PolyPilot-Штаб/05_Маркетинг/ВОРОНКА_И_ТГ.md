## Схема (Funnel 1.0 — актуальная)

```text
Short Content (Reels/Shorts/X)
  → PolyPilot Radar (media)
  → Telegram Hub / guest-event (вау 60–90 сек)
  → Telegram Bot (72h)
  → PolyPilot Starter (4 990–9 990 ₽)
  → Early Access → PRO later (после real PIE-output)
```

**Deprecated (не использовать до CEO-решения):**

```text
Креатив → guest-event → Pulse + PRO Trial 7 дней → PRO 2 990 ₽
```

---

## Правила

- **ТГ канал** — бесплатный hub, не касса
- **Деньги** — через `PolyPilot Starter` (manual payment / pre-order на старте)
- **Обучение** — в `learn.html` + Starter mini-course
- **PRO подписка** — гипотеза, не первый CTA
- **Не обещать прибыль** — см. [FUNNEL_1_0/BRAND_GUARDRAILS.md](FUNNEL_1_0/BRAND_GUARDRAILS.md)

## Бот (72 часа) — PolyPilot Starter

> Полная sequence: [FUNNEL_1_0/BOT_SEQUENCE_72H.md](FUNNEL_1_0/BOT_SEQUENCE_72H.md)

| Время | Содержание |
|-------|------------|
| 0 | Welcome + разбор открыт → guest-event deep link |
| +4ч | Движение вероятности / context update |
| +24ч | 3 события + education moment |
| +48ч | PolyPilot Starter intro |
| +72ч | Last call Starter + waitlist |

## Канал

1 пост/день + кнопка в **конкретное событие**.

Приоритетные сегменты: новички PM, semi-active users, macro/news — см. [FUNNEL_1_0/SEGMENT_MAP.md](FUNNEL_1_0/SEGMENT_MAP.md).

---

## Триггеры Starter (не PRO)

1. 2-й открытый guest-event  
2. Клик «Хочу в Starter» в bot  
3. День 3 bot (soft mention)  
4. День 5 bot (full offer)

# Brand Guardrails — Funnel 1.0

> Brand architecture и правила контента: высокий CTR без репутационного удара по PolyPilot.

---

## Brand Architecture

```text
PolyPilot (Official)
  → продукт, методология, аналитика, доверие, disclaimers

PolyPilot Radar / Research
  → события, разборы, графики, newsjacking, daily feed

Telegram Hub (RU)
  → главный acquisition hub, бесплатный top-of-funnel

Telegram Bot
  → 72h nurture, intent capture, Starter applications

Media Syndication (Reels / Shorts / X)
  → переупаковка Event Content Pack, discovery

Meme / Viral Account (optional, later)
  → ограниченная связь с PP, без прямых обещений, без «сигналов»
```

## Роли Брендов

| Бренд | Тон | Обещает | Не обещает | CTA |
|-------|-----|---------|------------|-----|
| **PolyPilot Official** | Спокойный, analytical | Метод, разбор, прозрачность | Прибыль, сигналы | Early access, learn, event |
| **PolyPilot Radar** | Быстрый, event-driven | Инсайт, контекст, «что рынок думает» | Guaranteed edge | TG, guest-event, report |
| **Telegram Hub** | Полезный, daily | Разборы, watchlist, education | «Забери деньги рынка» | Bot, Starter |
| **Short-form media** | Hook-heavy, visual | Curiosity, conflict, education moment | ROI, «300%» | Link in bio → TG |

## Почему Нельзя «Disposable Marketing Account»

Идея «маркетинговый аккаунт обещает, PP не обещает» **опасна**.

Если канал ведёт в PolyPilot:

- пользователь считает это одним проектом;
- негатив на канале = негатив на PP;
- «scam channel» убивает conversion на Starter;
- юридически и репутационно связь всё равно видна.

**Правильная конструкция:**

- media brand может быть **острее по тону**, быстрее по инфоповодам;
- PP brand остаётся **analytical layer** с disclaimers;
- edgy hooks ведут к **разбору / обучению**, не к «поставь».

## Allowed Hooks (Можно)

| Категория | Примеры |
|-----------|---------|
| Education | «70% на Polymarket ≠ 100% шанс» |
| Conflict | «Рынок может ошибаться — вот почему» |
| Anomaly | «Цена +12pp за сутки, но evidence слабый» |
| Risk | «3 риска, которые большинство не читает» |
| Method | «Как мы раскладываем вероятность на 7 компонентов» |
| News | «Что рынок думает о решении ФРС прямо сейчас» |
| Resolution | «Люди не читают resolution criteria — и теряют деньги» |
| Curiosity | «Почему smart money смотрит на это событие» |

---

## Banned Claims (Нельзя)

| Запрет | Почему |
|--------|--------|
| «Гарантированная прибыль» | финансовый совет, scam-vibe |
| «Сигнал / инсайд / точный вход» | betting-tipster positioning |
| «300% без риска» | fraud pattern |
| «PolyPilot всегда прав» | ложное доверие без Track Record |
| «Mock/demo как real analysis» | разрушает trust |
| «Забери деньги с рынка» | aggressive gambling CTA |
| «PRO trial / подписка» как первый CTA | не соответствует текущему CEO-фокусу |
| Track Record без реальных данных | misleading marketing |

## CTA Rules

### Разрешённые CTA (по приоритету)

1. «Полный разбор в Telegram» → bot / channel
2. «Открыть событие на PolyPilot» → guest-event
3. «Получить 3 live разбора» → PolyPilot Starter
4. «Научиться читать Polymarket» → learn / mini-course
5. «Early access / waitlist» → форма / bot
6. «Open on Polymarket» → только после проверки referral rules + disclaimer

### Запрещённые CTA

- «Купи PRO сейчас» (до real PIE-output)
- «Поставь YES/NO»
- «Гарантированный edge»
- «Платный Telegram» как первый шаг

## Content Zones

| Зона | Использование | Примеры |
|------|---------------|---------|
| **Белая** | основа всех каналов PP | education, method, risk, breakdown |
| **Серая** | Radar / Shorts с контролем | urgency без обещания прибыли, «рынок двинулся» |
| **Тёмная** | не для бренда PP | «сигналы», «забери деньги», fake urgency |

---

## Disclaimer Block (обязателен)

На guest-event, в bot, в offer copy:

```text
PolyPilot — аналитический и образовательный инструмент.
Не финансовый совет. Не обещаем прибыль.
Prediction markets связаны с риском потери средств.
```

## Escalation To CEO

Вернуть в `01_CEO`, если:

- хотим запустить meme/viral account с прямой связью с PP;
- хотим paid ads с money hooks;
- хотим Polymarket referral CTA до проверки правил;
- negative feedback ratio > 5% на «scam/signal» comments.

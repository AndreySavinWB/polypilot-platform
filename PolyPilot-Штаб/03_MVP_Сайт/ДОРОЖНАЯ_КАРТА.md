# POLYPILOT — ДОРОЖНАЯ КАРТА MVP (HTML)

> [[ДОМ_ШТАБ]] · [[ОБЗОР_MVP]] · [[КАРТА_ПЕРЕХОДОВ]]

> Цель ближайшего этапа: **рабочий сайт в браузере** — все экраны, кнопки и переходы как в реальном продукте.  
> **Без** живых AI-агентов и backend — только качественные моки и симуляция состояний.  
> Результат оценивается **фокус-группой**.

Связанные документы:
- [[КОНТЕКСТ_ПРОЕКТА_2.0]]
- [[МОНЕТИЗАЦИЯ]]
- [[ГЛАВНАЯ_СТРАНИЦА]] · [[МЕНЮ_ПЛАТФОРМЫ]] · [[AI_КАРТОЧКА_СОБЫТИЯ]]

---

## Что строим (одним абзацем)

**Interactive HTML prototype** = PolyPilot, который *ощущается* настоящим: sidebar, лента событий, карточка closed/open, War Room с анимацией, воронка Guest → Pulse → PRO Trial → paywall, тарифы, Proof Track. Данные — JSON/JS. Регистрация и оплата — **имитация** (модалки + переключатель режима для демо).

---

## Что НЕ строим сейчас

| Не делаем | Почему |
|-----------|--------|
| Backend, API, БД | После валидации UX |
| Реальные агенты / LLM | Только UI «штаба агентов» |
| Polymarket API | Статичные/полустатичные моки |
| Telegram-бот | В прототипе — кнопка «Войти через Telegram» → модалка успеха |
| Платежи | Экран «оплата прошла» + смена `userTier` в localStorage |
| Мобильное приложение | Адаптив в Phase 6, не отдельный продукт |

---

## Принципы (чтобы не путаться)

1. **Сначала карта переходов, потом пиксели** — Phase 0 обязательна.  
2. **Один design system** — цвета, типографика, sidebar, карточка — до массовой вёрстки страниц.  
3. **Ядро = Event Card** — всё остальное вокруг неё; не начинать с «Тарифов».  
4. **Состояния пользователя** — Guest / Pulse / PRO Trial / PRO — симулируем с первого дня (localStorage).  
5. **Старая модель Lite** в UI **не используем** — только Guest / Pulse / PRO ([[МОНЕТИЗАЦИЯ]]).  
6. **Каждая фаза = открываемый URL** — можно показать фокус-группе частичный результат.  
7. **Правки видения** — фиксируем в штабе; в коде следуем **2.0 + МОНЕТИЗАЦИЯ**.

## Симуляция состояний (без backend)

В `assets/js/state.js`:

| `userTier` | Поведение |
|------------|-----------|
| `guest` | Edge размыт, War Room 2 агента, paywall на Check |
| `pulse` | 5 событий/день, лимиты, нет полного Edge |
| `trial` | 7 дней PRO (баннер + дата в localStorage) |
| `pro` | всё открыто |

**Для фокус-группы:** в `settings.html` переключатель «Режим демо: Guest / Pulse / Trial / PRO» (скрытый от обычного UI или внизу для модератора).

**Для воронки:** кнопка «Войти через Telegram» → модалка → `trial` + редирект на `events.html`.

## Мок-данные

Файл `data/events.json` — **минимум 10 событий**:

- 3 «горячих» (высокий Edge, для креатива и guest landing)
- 4 обычных
- 2 закрытых (resolved, для Autopsy)
- 1 для Compare пары

Каждое событие: поля из [[AI_КАРТОЧКА_СОБЫТИЯ]] + `warRoom` (5 агентов с текстами) + `edgeScore` + `proofTrackEntry`.

**Не генерировать лор на лету** — тексты пишем один раз, правим в штабе при необходимости.

- 4 карточки мониторинга: пульсирующий статус, описание, время, источник

**Блок 6 — War Room**
- 5 агентов, каждый кликабелен (аккордеон)
- Развёрнутый агент: вердикт-бейдж, полный анализ, доказательства, шкала уверенности, теги источников
- Только один агент открыт одновременно
- Вердикты на понятном языке: ПОДДЕРЖИВАЕТ / ХОРОШИЙ ЗНАК / ЕСТЬ РИСКИ / С ОСТОРОЖНОСТЬЮ / ИСТОРИЯ ГОВОРИТ ДА / МАЛОВЕРОЯТНО / ПЛОХОЙ ЗНАК / НЕТ СИГНАЛА / СЛАБЫЙ НАМЁК

### Данные (`data/events-data.js`)

- 3 события: ФРС ставка, Bitcoin $150k, Рейтинг Трампа
- Каждый агент имеет поля: `detail`, `evidence`, `sources`, `verdict`, `verdictColor`, `confidence`
- Все тексты упрощены — без биржевого жаргона, для широкой аудитории
- Изображения событий: AI-generated `.jpg` в `assets/img/events/`

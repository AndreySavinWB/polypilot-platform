# Обзор HTML MVP

## Что это

Интерактивный прототип в браузере: **все экраны и переходы** как у реального PolyPilot.

## Что внутри

- Guest / Pulse / PRO Trial / PRO (localStorage)
- Карточка closed/open + War Room (мок)
- Воронка: guest landing → «Telegram» → trial → paywall
- Proof Track, PP Check, Compare — статичные моки
- 10 событий в `events.json`

## Чего нет

- Backend, API, Polymarket, LLM, реальные платежи, TG-бот

## Где код

Папка: `PolyPilot-MVP/` (рядом с штабом). См. README там.
